CONVOCATION INVITATION LANDING PAGE

Files:
- index.html : landing page
- preview.png : WhatsApp/social preview image

IMPORTANT: Before publishing, edit index.html and replace:
1. PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE with your existing Convocation Invitation Manager web-app URL.
2. https://YOUR-PUBLIC-PAGE-URL/ in og:url with the public URL of this landing page.
3. https://YOUR-PUBLIC-PAGE-URL/preview.png in og:image and twitter:image with the public image URL after hosting.

For WhatsApp link previews, the page and preview image must be publicly accessible over HTTPS. A Google Apps Script URL may not reliably expose Open Graph metadata, so host this static landing page on a service such as GitHub Pages or Netlify.
After publishing, share the landing-page URL in WhatsApp. If WhatsApp cached an old preview, paste the link into a new chat or use a preview-debugging/caching refresh service where available.
